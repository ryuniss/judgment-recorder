# Companion Q6 이식 범위

`companion-v2`의 `q6-only-v1`은 main의 Q6 문구와 의미적 발화 조건(선택이 카드의 우선순위와 어긋날 때)을 이식한다. 의미 판단은 모델이 한다. UI에서 선택을 확정한 때로 제한하지 않는다. Q1–Q11 전체 체계, 시작·마무리 질문, Q6 → Q5 → Q9 → Q7 → Q4 → Q8의 경쟁 순서는 이식하지 않았다. Q6가 아닌 경우에는 수신 확인만 반환한다. 따라서 전체 질문 체계와 발화 빈도가 같다고 주장하지 않는다.

## 입력과 저장

학생이 상단 ‘1순위 기준’에서 기준과 이유를 직접 입력한다. 기준·의도 카드에서 의도, 떠오르는 이미지, 1·2순위 기준, 탐색 질문을 받는다. Q6 모델 입력은 명시적인 1순위 기준과 대화이며 전체 팀 카드의 시작 질문 절차를 재현하지 않는다. 변경할 때 criterion_cards에 새 버전을 추가한다. 빈 기준도 명시적인 새 버전으로 저장할 수 있다. 과거 기준을 덮어쓰지 않는다.

실제 라운드에서 대화를 보낼 때 해당 참여자의 연습을 제외한 대화와 당시 기준을 question_events.context_json에 고정한다. 선택 칩 확정은 요구하지 않는다. 공급자 실패 후 재시도해도 최초 입력과 기준을 사용하며 같은 요청에 답을 두 번 저장하지 않는다. 질문 ID, 모델, 원응답(모델이 제시한 근거 포함), main 방식의 template_ok, 실제 전송 결과를 연구자 원 기록에 보존한다. 모델이 작성한 근거는 학생이 확인한 판단이 아니다. 학생용 탐색 지도에는 이 내부 분류를 표시하지 않는다.

## main과 다른 보호 조건

- 기준이 비었으면 모델 호출 없이 Q6를 차단한다(outcome=missing_priority).
- 연습에는 Q6를 적용하지 않는다.
- demo 모드는 고정 응답이며 Q6 판정 실험이 아니다(outcome=demo).
- main의 checkTemplate은 공백·따옴표 등을 제외한 고정 조각의 순서를 검사하는 충실도 검사다. 같은 검사를 Python으로 이식했다.
- 추가로 실제 보낼 Q6가 저장된 기준을 그대로 채운 템플릿인지 검사한다. 바꾼 질문·다른 기준·추가 질문은 보내지 않고 수신 확인을 보낸다(outcome=invalid_template_or_slot). 원응답과 검사 결과는 남긴다. 이 차이는 방법 기술에 명시해야 한다.
- 이 검사는 의미적 발화 조건이 맞았는지 보장하지 않는다. 모델이 잘못 Q6를 고르면 형식이 맞는 Q6가 나갈 수 있다.

## 검증과 한계

`python -m unittest companion.tests.test_q6`는 S3를 포함한 입력 전달, 고정 공급자 응답의 Q6/NONE 처리, 문구 검사, 기준 없음 차단, 재시도·격리·이력 저장을 검증한다. S3에서 실제 모델이 Q6를 고르는 능력을 검증한 것은 아니다.

`python -m companion.tests.q6_browser`는 실제 Chromium에서 기준 저장 실패/재시도·새로고침, Q6 표시, 질문 당시 기준 보존을 검증한다. 공급자 응답은 fixture다.

실제 모델 점검: OPENAI_API_KEY를 안전하게 환경에 설정한 뒤 `AI_MODE=live python -m companion.tests.q6_live`를 실행한다. S3/조건 비해당/기준 없음의 관측 결과를 JSON으로 출력한다. 모델 의미 판단은 비결정적이므로 1회 통과를 일반적 조건 충족의 보장으로 보지 않는다. 배포 환경이 demo이면 워크숍에서 Q6는 나오지 않는다.

## 최신 시안과 구분

2026-11-22에 다시 제공된 HTML의 06에서 선택/보류/제외/아직 모르겠어요, 이유 미기록, 판단 전 범례, 발언 저장과 판단 분리, ‘후속 개선안 · 프로토콜 미반영’ 중립 질문을 확인했다. 중립 질문은 이 프로토콜에 넣지 않았다. 이후 사용자 요청에 따라 실제 앱을 06 이미지 캔버스·대화 구성과 01 카드, 03 정리본, 04 모바일 탭의 디자인으로 변경했다. 이미지-이미지 다중 출처와 실시간 판단 이력을 추가했다. 02의 별도 3열 분류 패널 대신 06을 주 작업 화면으로 사용한다. 예시 문구·데이터와 미구현 Q 질문은 화면에 실제 기록처럼 표시하지 않는다.
